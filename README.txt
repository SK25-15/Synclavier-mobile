SYNCLAVIER II MOBILE — prototype

This is an installable progressive web app (PWA) prototype with a two-octave touch keyboard, Web Audio FM-style synthesis, presets, envelope controls and local preset saving.

TO INSTALL ON IPHONE
1. Host the contents of this folder on an HTTPS website (for example GitHub Pages).
2. Open that HTTPS address in Safari on your iPhone.
3. Tap Share, then Add to Home Screen.
4. Open Synclavier from the Home Screen and tap a key to enable audio.

LIMITATIONS
- This prototype is not an AUv3 plugin and cannot be loaded as an instrument inside GarageBand iPhone.
- It does not yet provide MIDI export/virtual MIDI routing to GarageBand.
- It is inspired by the Synclavier II; it is not an exact recreation or official product.
- For GarageBand integration, a native AUv3 extension needs to be built and signed using Apple's development toolchain, normally Xcode on a Mac.
